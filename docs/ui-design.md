# 知行工作台界面

沿用已评审原型的学习群侧栏、对话区、学习团队与项目档案三栏布局，主色为靛紫；四个角色使用字母/汉字标识与名称同时区分。页面内容来自 API，草稿保存在浏览器并按项目隔离。

UI/UX skill 搜索返回的营销页面结构不适合该工作台，因此不采用其布局；采用匹配的扁平样式、受控表单、焦点管理与可见键盘焦点建议。以系统中文字体为主，不依赖远端字体。消息保留原文，不执行 Markdown HTML。

窄屏将学习群改为下拉切换，群资料和档案在原生 dialog 中打开。支持中文输入法、Enter 发送、Shift+Enter 换行、Escape 关闭、原生模态焦点约束和 reduced-motion。角色状态来自运行记录与派活事件，未发生的协作不展示为正在处理。

完成检验政策、目标调整和成绩证据使用独立卡片。未确认政策、缺题、待复核与过期证据均明确呈现。模型配置或网络失败不会替换为模拟成功；仅显式 local DEMO_MODE 使用测试数据。
