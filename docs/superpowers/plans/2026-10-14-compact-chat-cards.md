# 精简计划卡片与交接顺序

按用户明确要求，在当前 codex 分支实施，不改变模型数据、密码或学习记录。

1. 对话中的整体计划只显示课程数量与资料链接；今日安排只显示目标与链接，不展开知识点、活动、产出和检索摘要。完整内容保留在点开的窗口中。
2. 将当前轮次的交接提示放到对应专家回复前。公开消息补充 run_id，优先通过已提交消息事件的顺序匹配，缺少标记时用同轮专家与时间匹配；保留去重和当前轮次过滤。
3. 先用回归用例复现摘要过多和交接位置错误，再实现；运行测试、类型检查、构建，部署 Cloudflare 并实测；同步当前 GitHub PR。
